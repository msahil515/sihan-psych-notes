# Chapter 7: Long-Term Memory Systems

**What this chapter is really about.** Chapter 6 treated memory mainly as processes. This chapter asks a structural question: is long-term memory one store or several? Long-term memory holds what happened at your cousin's wedding, the fact that Delhi is India's capital, how to ride a scooter, and the reason a word seen a minute ago now "pops out" faster. Atkinson and Shiffrin (1968) drew all of that as a single box; almost nobody accepts that now. The chapter sets out the standard replacement, a family tree of separate **memory systems** headed by the split between **declarative (explicit)** and **non-declarative (implicit)** memory, and then spends its last third on why that tree is under attack from theories built around **processes** rather than systems.

The evidence that drives almost every argument comes from brain-damaged patients. An amnesic patient who cannot remember breakfast but improves at a motor skill day after day is a living demonstration that "memory" is not one thing. A patient with semantic dementia who has lost the meaning of "zebra" but remembers what she did yesterday shows the reverse. Clinical psychology entrance papers love this chapter for exactly that reason: almost every key finding is a patient, and almost every patient is an MCQ.

**How to read this chapter.** 7.1 sets up the problem (amnesia, HM, the declarative versus non-declarative taxonomy). 7.2 splits declarative memory into episodic and semantic memory; 7.3 and 7.4 go inside each. 7.5 covers priming and skill learning. 7.6 is the turn: why consciousness may be the wrong dividing line, and what Henke (2010) and Cabeza and Moscovitch (2013) offer instead. The chapter opens with a model and closes by dismantling it, so read 7.1 and 7.6 together.

## 7.1 Introduction

### From one store to several systems

The starting point is the sheer variety of what long-term memory holds. It contains personal events (last summer's holiday), general facts (Paris is the capital of France), and know-how (riding a bicycle). Much of our knowledge is also packaged into **schemas**, organised bundles of knowledge about familiar situations, which are put to heavy use when we understand language (the book develops this in Chapter 10).

Given that variety, the authors judge it unlikely that a single long-term store, as in Atkinson and Shiffrin's (1968) multi-store model, could do all of this. The field gradually accepted that there are several major long-term memory systems. A well-known list is **Schacter and Tulving (1994)**, who named **four**:

1. **Episodic memory**
2. **Semantic memory**
3. **The perceptual representation system** (the system thought to underlie perceptual priming)
4. **Procedural memory**

**Squire (2009a)** later reconsidered how many systems there are and what they are like in the light of brain research, and the chapter returns to these competing views at the end.

> **Trap.** The 7th edition credits Schacter and Tulving (1994) with **four long-term** systems. Classic background: their paper listed **five** major systems, the fifth being working (primary) memory, a short-term system, so older keys may say "five". Both differ from Tulving's original two-way split (1972: episodic and semantic) and his three nested systems (classic background: Tulving, 1985: procedural, semantic, episodic).

### Amnesia: what it is and what it is not

**Amnesia** is a condition, caused by brain damage, in which long-term memory is severely impaired. It gives the strongest hint that long-term memory has separate parts, because the damage takes out some kinds of memory and spares others.

The book first corrects the cinema version of amnesia (Baxendale, 2004). Film characters usually lose their past after a head injury but learn new things normally; real patients usually show the reverse, with **new learning badly impaired**. *Memento* (2000), whose hero Leonard Shelby cannot retain new information, is a rare accurate portrayal. Complete personality change (Goldie Hawn's socialite turned devoted mother in *Overboard*, 1987) is extremely rare in reality, and a second blow to the head is not a cure.

**Causes.** Bilateral stroke can cause amnesia, but the **most common cause is closed head injury**. Closed head injury, however, usually brings several cognitive problems at once, which makes it difficult to isolate the memory deficit. For that reason much research, especially early research, used patients whose amnesia came from **chronic alcohol abuse**, that is, **Korsakoff's syndrome**.

> **Trap.** "The most common cause of amnesia" is **closed head injury**, not Korsakoff's syndrome. Korsakoff's syndrome is the most *studied* cause in early research, chosen because its patients seemed cleaner to work with. Examiners exploit the difference between common and well-studied.

### Four problems with Korsakoff patients

Using Korsakoff patients as the model of amnesia has four drawbacks, and each one is a reason to be cautious about any conclusion drawn from them.

1. **Gradual onset.** The amnesia develops slowly, because it is caused by a growing deficiency of the vitamin **thiamine** linked to chronic alcoholism. With a gradual onset you often cannot tell whether a given past event happened before or after the amnesia began, which muddies the line between anterograde and retrograde amnesia.
2. **Widespread damage.** The damage usually includes the **medial temporal lobes**, especially the **hippocampus** (Figure 7.1 in the book shows the structures involved in memory storage and consolidation), but it often extends to the **frontal lobes**. Frontal damage produces cognitive problems that are not specifically about memory, so the memory picture is contaminated.
3. **Variability between patients.** The exact damage, and so the exact memory profile, differs from patient to patient. Korsakoff's syndrome is usually, though not always, preceded by **Wernicke's encephalopathy**, marked by confusion, lethargy and inattention (Fama et al., 2012). This variability makes generalising across patients risky.
4. **No direct read-out of the damage.** Over time, brain plasticity and learned compensatory strategies allow patients to soften some of their symptoms (Fama et al., 2012), so what you test years later is not a pure measure of what the damage did.

> **Trap.** Korsakoff's syndrome is caused by **thiamine (vitamin B1) deficiency** associated with chronic alcoholism, and it is typically preceded by **Wernicke's** encephalopathy. Do not confuse Wernicke's *encephalopathy* (an acute confusional state) with Wernicke's *aphasia* (a language disorder from posterior temporal damage). Same name, different conditions.

### In the real world: the case of HM

HM is the most studied amnesic patient in history. After his death in **2008** he was revealed to be **Henry Gustav Molaison**. He had very severe epilepsy from the age of **10**, and on **23 August 1953** he underwent surgery to treat it, in which the **medial temporal lobes, including the hippocampus**, were removed (classic background: the removal was bilateral and was carried out by the neurosurgeon William Scoville).

The surgery devastated his memory for new material. Corkin (1984) described a man who, decades after the operation, did not know where he lived or who looked after him and could not say where his most recent meal had been eaten. In 1982 he failed to recognise a photograph of himself taken on his fortieth birthday in 1966. When shown faces of people who became famous after his amnesia began, he could identify only **John Kennedy and Ronald Reagan**. His language was affected too: Mackay et al. (2011) found he struggled to plan coherent sentences when speaking.

Research on HM, beginning with **Scoville and Milner (1957)**, transformed the understanding of long-term memory (Squire, 2009b; Eichenbaum, 2015). The book gives three reasons:

1. **More than one long-term memory system.** HM could still form several kinds of long-term memory. He learned **mirror tracing** (drawing shapes seen only in a mirror) reasonably well and kept some of this learning for **one year** (Corkin, 1968). He also improved on the **pursuit rotor** (keeping a stylus on a moving target). A man who cannot remember the practice sessions but gets better at the task must be using a memory system other than the damaged one.
2. **Short-term and long-term memory are distinct.** He had good sustained attention and essentially intact short-term memory. The damage hit long-term memory while leaving short-term memory working, which is the kind of dissociation Chapter 6 uses to separate the two.
3. **The medial temporal lobes matter for long-term memory, but are not the permanent store.** The surgery's dramatic effect implicates the medial temporal lobes and hippocampus in forming long-term memories. Yet HM remembered events from long before the operation fairly well, which suggests memories are **not stored permanently in the hippocampus**.

### The amnesic syndrome

Korsakoff patients are sometimes described as showing an **amnesic syndrome** with four features:

| Feature | What it means |
|---|---|
| **Anterograde amnesia** | Marked difficulty remembering new information learned **after** the onset of amnesia. HM had this severely. |
| **Retrograde amnesia** | Difficulty remembering events that happened **before** the onset of amnesia. |
| **Near-normal short-term memory** | Only slight impairment on measures such as **digit span** (repeating back a random string of digits). |
| **Some residual learning** | Some learning, for example of **motor skills**, survives after onset. |

Do the two directions of amnesia depend on the same brain regions? **Smith et al. (2013)** measured both in **11 patients** with medial temporal lobe damage and found a strong correlation, **r = +0.81**, between the severity of their anterograde and retrograde amnesia. That suggests a shared neural basis when damage is confined to the medial temporal lobes. The correlation is often much weaker when the damage spreads to other regions, so the two can come apart in patients with more extensive lesions.

> **Trap.** **Antero**grade = forward = cannot learn **new** information after onset (HM's defining problem). **Retro**grade = backward = cannot retrieve **old** information from before onset.

### Declarative versus non-declarative memory

Work with amnesic patients like HM produced the distinction that organises most of the chapter. Amnesic patients both inspired it and supplied some of its strongest evidence.

**Declarative memory** is memory that involves **conscious recollection** of events and facts. The name comes from the idea that these memories can be "declared" or put into words, but the category also covers some memories that cannot be described verbally. It is also called **explicit memory**, and its content is **knowing that** something is the case. It has two main forms:

- **Episodic memory**: personal experiences or events that happened at a particular place and time.
- **Semantic memory**: general knowledge about the world, concepts, language and the like.

**Non-declarative memory** does **not** involve conscious recollection. We infer it from **changes in behaviour**. A learner cyclist rides better week by week without being able to consciously recall what has been learned. Non-declarative memory is also called **implicit memory**. Its main forms are:

- **Procedural memory**: memory for skills such as playing the piano or riding a bicycle; **knowing how** to perform actions.
- **Priming**: the processing of a stimulus is influenced by an earlier presentation of a related stimulus. If a picture of a cat is flashed very briefly, you identify it as a cat more easily if you have recently seen a similar cat picture; the first picture acted as a **prime**.

Classic background: the "knowing that" versus "knowing how" contrast goes back to the philosopher Gilbert Ryle, and the terms explicit and implicit memory were popularised by Graf and Schacter (1985). The 7th edition uses declarative/explicit and non-declarative/implicit as interchangeable pairs.

The amnesic evidence fits the distinction neatly. HM had extremely poor declarative memory for personal events after onset and for faces that became famous in later decades, yet showed reasonable learning on **mirror tracing, the pursuit rotor and perceptual identification**, all of them non-declarative tasks. The book notes that most amnesic patients show a similar profile.

> **Trap.** Priming and procedural memory are **sister** categories under non-declarative memory, so "priming is a form of procedural memory" is wrong (7.5 gives their two differences). And "declarative = verbal" is too narrow: the defining feature is **conscious recollection**, not verbal report.

### The standard taxonomy (Figure 7.2)

The book's sketch-map of the chapter (Figure 7.2, taken from Henke, 2010) is the standard memory systems account. The figure image is lost, but its caption and the surrounding text give its structure:

| Long-term memory | Subdivisions |
|---|---|
| **Declarative** | Episodic memory; semantic memory |
| **Non-declarative** | Procedural memory; priming; simple classical conditioning; habituation and sensitisation |

The second assumption built into the figure matters as much as the boxes: **each form of memory is linked to its own brain regions**. In the text, for example, episodic memory is tied to the **medial temporal lobe (including the hippocampus)** and **not** to the **basal ganglia (including the striatum)**.

Classic background (Squire's widely reproduced version of this taxonomy, which Indian papers often use): declarative memory depends on the medial temporal lobe and diencephalon; procedural skills and habits on the striatum; priming and perceptual learning on the neocortex; simple classical conditioning on the amygdala (emotional responses) and cerebellum (skeletal responses); and non-associative learning (habituation and sensitisation) on reflex pathways. The 7th edition's point is that this neat one-system-one-region mapping is too rigid, as the next subsection shows.

### Limitations of the traditional memory systems approach

The memory systems approach explains a great many findings and is still very influential. But theorists increasingly regard it as incomplete (Henke, 2010; Hannula & Greene, 2012; Cabeza & Moscovitch, 2013). The core objection is that it is **oversimplified**: it is unlikely that each system has its own separate processes housed in its own brain area. The authors keep one door open throughout the chapter: a **more complex** version of the systems approach might still be able to absorb most of the awkward findings.

One alternative previewed here is the **component process framework** discussed by **Cabeza and Moscovitch (2013)**. Instead of a few fixed systems, it proposes **many processing components** that are combined flexibly according to what the task demands.

> **Key study, Sadeh et al. (2011).** The standard taxonomy predicts that episodic memory uses the hippocampus but not the striatum. Sadeh et al. found that items later **successfully recognised** in an episodic memory test had been accompanied at learning by **increased activity in the striatum as well as the hippocampus**. One reading is that effective episodic learning involved the hippocampus and striatum working interactively.

The evaluation the book attaches is important: these are **neuroimaging data and therefore correlational**. They show the striatum was active when episodic learning succeeded; they cannot show that episodic learning **requires** the striatum. The same objection applies to almost every imaging study in the chapter.

## 7.2 Declarative Memory

### Tulving's two kinds of declarative memory

You remember what you had for breakfast this morning, and you also know that "le petit déjeuner" is French for breakfast. Both are declarative memories, but **Tulving (1972)** argued that they are very different kinds of memory, and he coined the terms **episodic memory** and **semantic memory** for the difference (Eysenck and Groome, 2015, review how the idea has developed since).

**Episodic memory** is memory for personal experiences or episodes that happened at a particular place and time. Its distinguishing feature is that it lets us retrieve **where and when** events in our own lives took place. Tulving's later description (Tulving, 2002) is worth knowing in outline because examiners quote it. He characterised episodic memory as a system that:

- **evolved recently** in evolutionary terms,
- **develops late** in childhood,
- **deteriorates early** in old age,
- is oriented to the past,
- is **more vulnerable** to neural dysfunction than other memory systems, and
- makes possible **mental time travel**, travelling back in subjective time from the present so as to re-experience one's own earlier experiences.

**Semantic memory** is general knowledge about the world, concepts, language and so on. Binder and Desai (2011) describe it as each person's store of world knowledge, abstracted from the particular experiences in which it was acquired. Because it has been abstracted from those experiences, it is **conceptual**: generalised and without reference to any specific occasion.

Classic background: Tulving (1985) linked episodic remembering to **autonoetic** ("self-knowing") consciousness, the feeling of re-living the past, and semantic memory to **noetic** ("knowing") consciousness. The 7th edition conveys the same idea through the phrase "mental time travel".

> **Trap.** "Recently evolved, late-developing, early-deteriorating" describes **episodic** memory in Tulving (2002), not semantic memory. Semantic memory is the more robust system; that asymmetry is exactly why amnesic patients so often keep more semantic than episodic memory.

### Episodic and semantic memory work together

The two systems usually cooperate. Remembering meeting a friend at a coffee shop last week is episodic (that event, that time, that place), but much of the content comes from semantic knowledge of coffee shops and of what coffee tastes like.

### Episodic versus autobiographical memory

Both are memory for personal experiences, so they are easy to merge. The book separates them on **significance and duration**. Much episodic memory is fairly **trivial and short-lived** (where you parked this morning). **Autobiographical memory** (Chapter 8) holds information about events and experiences of **personal significance**, and holds it for **long periods**.

> **Trap.** In this book episodic memory includes trivial, quickly forgotten personal events, while autobiographical memory is the long-lasting, personally significant subset. Both are declarative memory for personal experience (the chapter summary pairs them as "episodic/autobiographical").

### Episodic versus semantic memory: the evidence from amnesia

If episodic and semantic memory really are separate systems, they should come apart in important ways. Some of the strongest evidence for separation comes from brain-damaged patients (Greenberg & Verfaellie, 2010). The first question is about **anterograde** amnesia: after the onset of amnesia, can patients still acquire new semantic memories even when they cannot form new episodic ones?

> **Key study, Spiers et al. (2001).** A review of **147 cases** of amnesia involving damage to the **hippocampus or fornix**. **Episodic memory was impaired in every case**, whereas many patients had significantly milder semantic memory problems. The review also stressed that **none** of the cases was reported to have impaired **short-term memory**, typically tested by digit span.

The much larger effect of hippocampal damage on episodic than on semantic memory suggests the two are distinct. But "milder" is not "intact". The stronger test would be a patient with very poor episodic memory and **essentially normal** semantic memory.

> **Key study, Vargha-Khadem et al. (1997): Beth and Jon.** Two patients with **bilateral hippocampal damage** acquired early in life, before semantic memory had developed: **Beth at birth** and **Jon at age 4**. Both had very poor episodic memory for the day's activities, television programmes and telephone conversations. Yet both attended **ordinary schools**, and their semantic memory, judged from speech and language development, literacy and factual knowledge such as vocabulary, was **within the normal range**.

This looks like the dissociation the theory needs. The book adds a counterweight: in healthy people with an intact hippocampus, the hippocampus **is** used to acquire semantic memories (Baddeley et al., 2015). So Beth and Jon show that semantic learning *can* proceed without the hippocampus, not that it normally does.

**Jon on closer inspection.** **Gardiner et al. (2008)** found that Jon did have some semantic memory problems. When taught new geographical, historical and other facts, he learned **significantly more slowly** than healthy controls. Why then did he seem to acquire knowledge normally in everyday life? Gardiner et al. suggested he compensated by spending a great deal of time **repeatedly studying** such information. The overall verdict: Jon's semantic memory was **somewhat impaired**, but his episodic memory was **grossly deficient**.

**Explaining the difference.** Vargha-Khadem et al. (1997) proposed an anatomical split:

| Memory | Proposed basis |
|---|---|
| **Episodic** | Hippocampus |
| **Semantic** | The underlying **entorhinal, perirhinal and parahippocampal cortices** |

Beth's and Jon's damage was centred on the hippocampus, so their episodic memory suffered most. Why, then, do so many amnesic patients have severe problems with **both** kinds of memory? Probably because their damage covers the hippocampus **and** the cortices beneath it, which is very likely given that the two areas are adjacent.

> **Key study, Bindschaedler et al. (2011): VJ.** A boy with **severe hippocampal atrophy** but relatively spared surrounding areas, including the perirhinal and entorhinal cortex. His performance on semantic tasks such as vocabulary **rose over time at the same rate as healthy controls**, even though he was severely impaired on **82%** of episodic memory tasks. This fits Vargha-Khadem's anatomical account: spare the cortex under the hippocampus and semantic learning survives.

> **Trap.** Beth and Jon were damaged **before** semantic memory developed (birth, age 4), so they test semantic *acquisition*, not retention. Vargha-Khadem puts **episodic** memory in the **hippocampus** and **semantic** memory in the **entorhinal, perirhinal and parahippocampal cortices**; do not swap them.

### Retrograde amnesia: old episodes versus old facts

So far the question has been about learning new material. What about memories formed **before** the onset of amnesia?

Many amnesic patients show **much greater retrograde amnesia for episodic than for semantic memories**. The classic example is **KC**. Tulving (2002) reported that KC could not recollect any events he had personally experienced, yet his semantic knowledge from before his accident was still reasonably intact, and his general knowledge of the world was about what you would expect for someone of his education.

Three features of retrograde amnesia are worth separating:

- **Episodic retrograde amnesia often spans several years.**
- It usually shows a **temporal gradient**: **older memories are less impaired than more recent ones** (Bayley et al., 2006).
- **Semantic retrograde amnesia is generally small**, except for knowledge acquired **shortly before** the onset of amnesia (Manns et al., 2003).

(The book's sentence here has a slip, comparing older memories with "older ones"; the intended meaning is that remote memories survive better than recent ones.)

**Why does retrograde amnesia look like this?** Several theories compete (Kopelman & Bright, 2012):

1. **Consolidation theory.** Episodic memories undergo a long physiological **consolidation in the hippocampus**; after several years they are stored elsewhere and are then safe from hippocampal damage. This neatly explains the temporal gradient. Its weakness is that a consolidation process lasting **several years** is implausible.
2. **Episodic memories become semantic-like over time**, which protects them from brain damage. This predicts that remote semantic memories, such as vocabulary learned years before onset, should be relatively intact. In fact they are often forgotten, which counts against the theory.

Kopelman and Bright (2012) concluded that the data are confusing and contradictory and do not really support any of the main theories.

The book adds a simpler, partial explanation. An episodic memory usually rests on **one** learning experience, whereas most semantic memories (the meaning of a word, say) have been met **many** times. Fewer learning opportunities could explain, at least in part, why retrograde amnesia hits episodic memories harder.

> **Trap.** The temporal gradient (Ribot's law in older books, classic background) means **recent** pre-onset memories are lost **more** than remote ones; students reverse it. For this book, consolidation theory is weakened by its **years-long** consolidation, and Kopelman and Bright (2012) find **no** main theory well supported.

### Semantic dementia: the reverse pattern

Is there a condition with severe semantic loss but reasonably intact episodic memory? Yes.

**Semantic dementia** is a condition involving damage to the **anterior temporal lobes**, in which knowledge of the meanings of words and concepts is lost on a wide scale. Patients differ considerably in their exact symptoms and pattern of damage, but **episodic memory and executive functioning are reasonably intact in the early stages**.

Semantic dementia **always** involves degeneration of the **anterior temporal lobe**, so that region is central to semantic memory. The book proposes a division of labour within the temporal lobe:

- The **perirhinal and entorhinal cortex** probably help to **form** semantic memories.
- The **anterior temporal lobes** are where those memories are **stored** on a semi-permanent basis.

Patients with semantic dementia find it very hard to access most concepts in semantic memory (Mayberry et al., 2011), yet do well on several episodic tasks.

> **Key study, Adlam et al. (2009).** Patients with semantic dementia were asked to remember **what tasks** they had done **24 hours earlier**, **where** they had done them, and **when** in the session each occurred (the what, where and when of episodic memory). As a group they performed **comparably to healthy controls**.

### The double dissociation

Put the two clinical groups side by side and you have a **double dissociation**:

| | Episodic memory | Semantic memory | Damage |
|---|---|---|---|
| **Amnesic patients** | Very poor | Often fairly intact | Hippocampus / medial temporal lobe |
| **Semantic dementia** | Reasonably intact (early) | Very poor | Anterior temporal lobes |

A single dissociation (one group impaired on A but not B) could mean only that task A is harder. A double dissociation, where another group shows the opposite pattern, rules that out and is strong evidence that the two abilities rest on at least partly separate systems.

> **Trap.** Semantic dementia is **anterior temporal lobe** degeneration, not hippocampal damage, and it spares **episodic** memory early on. Students who have learned "temporal lobe = memory" will pick hippocampus. The correct pairings: **amnesia = hippocampus = episodic loss**; **semantic dementia = anterior temporal lobe = semantic loss**.

### Interdependence of episodic and semantic memory

The dissociation evidence argues for separate systems. Other evidence shows the two systems overlap in the brain and depend on each other in use.

> **Key study, Burianova et al. (2010).** Brain activation was compared during retrieval of **episodic, semantic and autobiographical** memories. The **same neural network** was active for all three types of declarative retrieval. In addition, activity fell in areas concerned with attending to external stimuli, as you would expect when attention turns inwards to memory.

> **Key study, Kan et al. (2009): semantic memory helps episodic learning.** Amnesic patients and controls learned the **prices of grocery items**, an episodic task. Some prices were **congruent** with prior knowledge of what such items cost (semantic memory), others **incongruent**. Healthy controls remembered congruent prices better, so their semantic knowledge served as a framework for new episodic learning. Amnesic patients with **fairly intact semantic memory** showed the same congruency advantage. Amnesic patients with **poor semantic memory** could not use their knowledge and showed **no congruency effect**.

> **Key study, Greenberg et al. (2009): episodic memory helps semantic retrieval.** Amnesic patients and controls did a **category-generation** (fluency) task, a semantic task: produce as many members of a category as possible. Some categories were chosen because episodic memory would help (kitchen utensils, things given as birthday presents: you can mentally walk through your kitchen or recall past birthdays); others were less likely to draw on episodic memory (things that are typically red). Amnesic patients did worse overall, but **especially badly on the episodic-friendly categories**, because controls used episodic memory as an efficient retrieval strategy and the patients could not.

Notice how the two studies mirror each other: Kan et al. show the semantic-to-episodic direction at **learning**, Greenberg et al. the episodic-to-semantic direction at **retrieval**.

### Evaluation

**Strengths of the separate-systems view.** There are **somewhat separate** episodic and semantic systems. Amnesic patients with hippocampal damage **always** have severely impaired episodic memory, while their semantic memory is often less affected. Semantic dementia patients show the opposite, at least early on. Together the two groups supply an important **double dissociation**.

**Limitations.** Most research has studied each type of memory **in isolation**. In reality the two are often **interdependent** at learning and at retrieval (Kan et al., 2009; Greenberg et al., 2009), and they share neural machinery (Burianova et al., 2010). Future research needs to work out how the two combine to improve learning and retrieval.

### Semanticisation of episodic memory

The last idea in this section blurs the boundary from a different direction. Suppose that as a child you spent a holiday a few miles from the sea and one day visited a seaside resort, laying down rich episodic memories of the trip. Years later you know that you once went to a seaside resort, but you have lost its name, the date, and every detail of what happened there. What began as an episodic memory has turned into a semantic one, stripped of its personal and contextual detail. This is **semanticisation**, the change of episodic memories into semantic memories over time, and it implies there is **no sharp line** between the two kinds of memory.

> **Key study, Harand et al. (2012).** Participants saw **almost 200 pictures** and were tested **three days** and **three months** later. Some picture memories stayed **episodic** at both delays (contextual details recalled both times). Others were episodic at three days but had become **semantic** by three months (the picture was recognised, but no context could be recollected). At three months the **hippocampus** was much more active for the memories that had stayed episodic than for those that had become semantic, which strengthens the case that some episodic memories really do turn into semantic ones.

## 7.3 Episodic Memory

### Very long-term episodic memory: the permastore

Most episodic memories fade a lot with time (Chapter 6). Some do not, and Bahrick's studies of memory over decades are the standard demonstration.

> **Key study, Bahrick et al. (1975).** Former students were tested on their high-school classmates using **yearbook photographs**. Forgetting was remarkably slight for retention intervals of up to **25 years**: performance was about **90%** for recognising classmates' **names**, recognising their **photographs**, and **matching names to photographs**. After almost **50 years**, performance was still very high on the **two photograph-based tests** but had **declined on name recognition**.

> **Key study, Bahrick et al. (2008).** Former college students recalled their **academic grades**. Distortions appeared soon after graduation, mostly in the form of **inflating** the actual grade, but after that the level of distortion stayed fairly **constant** over retention intervals of up to **54 years**.

**Bahrick (1984)** coined the term **permastore** for very long-lasting, stable memories, by analogy with **permafrost**, the permanently frozen subsoil of polar regions. What gets into the permastore is mainly information that was **very well learned in the first place**: classmates seen daily for years, grades checked and re-checked.

### How episodic memory is tested

To measure someone's episodic memory after they have studied, say, a word list, there are two broad families of test.

**Recognition tests.** In the basic version, items are presented one at a time and the participant decides whether each was in the study list. More elaborate recognition procedures also exist, as the next subsection shows.

**Recall tests**, in three basic forms:

| Test | What the participant does |
|---|---|
| **Free recall** | Produces the list items **in any order**, with no specific cues |
| **Serial recall** | Produces the items **in the order presented** |
| **Cued recall** | Produces items in response to **cues**; for example, study "cat - table", then at test get "cat - ???" |

### Recognition memory: familiarity and recollection

Recognition can be based on two different kinds of information. Diana et al. (2007) draw the distinction this way. **Recollection** is recognising an item because you retrieve **specific contextual details** of the occasion on which you met it. **Familiarity** is recognising an item because it **feels strong in memory**, without retrieving any specific details of the study episode.

The book's illustration is from the first author's own life. Walking through Wimbledon, Eysenck passed a man and was instantly confident he knew him, but could not think where he had seen him before. After some thought he placed him: the man was a clerk at the ticket office of Wimbledon railway station. Recognition began as **familiarity** (I know that face) and became **recollection** (I know where from). Classic background: Mandler (1980) made the same point with his "butcher on the bus" example, a face that feels familiar out of context until you recall that it belongs to your local butcher.

### The remember/know procedure

A practical way to separate the two processes is the **remember/know procedure** (Migo et al., 2012). Participants decide whether each test item is **Old** or **New**. For each item called Old, they then say whether they:

- **Remember** it: recognition comes with a conscious recollection of the item's earlier occurrence in the study phase (Gardiner, 1988). This corresponds to **recollection**.
- **Know** it: they are sure it was there but do not consciously recollect its occurrence. This corresponds to **familiarity**.

Classic background: the remember/know paradigm was introduced by Tulving (1985) and developed by Gardiner.

**Is this really two processes?** Sceptics argue that the only real difference is **trace strength**: strong memories produce "remember" judgements and weak memories produce "know" judgements, so one process along a single strength dimension would be enough. **Dunn (2008)** carried out a meta-analysis of **37 studies** using the remember/know procedure and argued that the findings could be explained by a **single process based on memory strength**.

Despite Dunn, the book concludes that **most evidence supports dual-process accounts**. One source is **event-related potentials (ERPs)**, which track the time course of recognition. Since recollection is the more complex process, drawing on a wider range of information, it should take longer than familiarity. Several studies confirm this (Addante et al., 2012):

| Process | ERP marker | Timing after stimulus onset |
|---|---|---|
| **Familiarity** | Negative peak, the **FN400** | **400 to 600 ms** |
| **Recollection** | Positive peak, the **late positive component** | **600 to 900 ms** |

A caution goes with this evidence: the FN400 may partly reflect **implicit memory** mechanisms rather than the explicit familiarity process researchers want to measure, so the ERP data are not easy to interpret.

> **Trap.** **Remember = recollection** (detail; late positive component, 600 to 900 ms). **Know = familiarity** (strength only; FN400, a frontal negativity, 400 to 600 ms). Dunn (2008, 37 studies) is the **single-process** dissenter; the book sides with **dual-process** theory.

### Familiarity and recollection in the brain: the binding-of-item-and-context model

**Diana et al. (2007)** proposed the **binding-of-item-and-context model** (often abbreviated BIC; Figure 7.3 in the book shows the three regions and the model). The idea is a division of labour among three medial temporal lobe regions:

1. **Perirhinal cortex** receives information about **specific items**: the "what" information needed for **familiarity** judgements.
2. **Parahippocampal cortex** receives information about **context**: the "where" information useful for **recollection** judgements.
3. **The hippocampus** receives both the "what" and the "where" information and **binds them** into item-context associations. That binding is what makes **recollection** possible.

Read as a flow: item information (perirhinal) and context information (parahippocampal) converge on the hippocampus, which ties them together. Familiarity needs only the first stream; recollection needs the bound product.

> **Trap.** **Perirhinal = item = "what" = familiarity.** **Parahippocampal = context = "where" = recollection.** **Hippocampus = binding = recollection.** The perirhinal/parahippocampal swap is one of the most reliable traps in this chapter.

### Findings: neuroimaging

> **Key study, Diana et al. (2007), meta-analysis.** Across imaging studies, **recollection** was linked to more activation in the **parahippocampal cortex and hippocampus** than in the perirhinal cortex, whereas **familiarity** was linked to more activation in the **perirhinal cortex** than in the parahippocampal cortex or hippocampus.

> **Key study, De Vanssay-Maigne et al. (2011).** A replication: old words correctly recognised with a sense of **familiarity** were associated with greater **bilateral perirhinal** activation than old words that were not recognised, and these perirhinal areas were **not** associated with successful recollection.

The book flags **two limitations** of this imaging evidence:

1. It is **correlational**, so it cannot show the hippocampus is actually **more essential** for recollection than for familiarity.
2. **Judgement type is confounded with memory strength**: recollected memories tend to be stronger. When this confound is removed, hippocampal activation for recollection and familiarity is usually **comparable** (Wixted & Squire, 2011).

### Findings: brain-damaged patients

Patient data can, in principle, give stronger evidence, because they can show what is necessary.

**Prediction 1: hippocampal damage should impair recollection more than familiarity.**

> **Key study, Bowles et al. (2010).** Amnesic patients who had had surgery removing much of the **hippocampus and amygdala** showed significantly impaired **recollection** but **not** impaired **familiarity**, as the model predicts.

Other research usually finds a slightly different pattern: amnesic patients with medial temporal lobe damage show a **minor** impairment of familiarity and a **much larger** impairment of recollection (Skinner & Fernandes, 2007). That is still a dissociation in degree.

> **Key study, Addante et al. (2012).** Amnesic patients had severely impaired recollection but relatively intact familiarity. Their ERPs fitted: they showed the familiarity-linked **FN400** (which, again, may partly reflect implicit memory), but **lacked the recollection-linked late positive component**.

**Prediction 2: perirhinal damage should impair familiarity and leave recollection largely intact.** This is the rarer and more theoretically valuable pattern.

> **Key study, Bowles et al. (2007, 2011): patient NB.** A woman who had surgery removing a large part of the **perirhinal cortex** (and adjacent **entorhinal** cortex). Her **recollection** was consistently **normal** across a range of materials, but her **familiarity** was impaired for **verbal** materials.

> **Key study, Brandt et al. (submitted): patient MR.** A woman whose damage was limited to the **entorhinal cortex**. Recognition tests showed **impaired familiarity for words** with **intact recollection**.

### Conclusions on familiarity and recollection

There is a lot of support for the idea that recognition depends on fairly separate processes of familiarity and recollection. Imaging contributes, but the most convincing evidence is from patients, because together they produce a **double dissociation**: many patients show reasonably intact familiarity with impaired recollection (hippocampal damage), while a few show the opposite (NB, MR, with perirhinal or entorhinal damage).

Essentially, recollection draws on **more information** than familiarity. That extra information is usually contextual, but it may also include information about the **cognitive control processes** used to search long-term memory. So it may eventually be necessary to distinguish **different forms of recollection** (Moulin et al., 2013).

| Patient | Damage | Familiarity | Recollection | Source |
|---|---|---|---|---|
| Amnesic surgical patients | Hippocampus and amygdala | Intact | Impaired | Bowles et al. (2010) |
| **NB** (female) | Perirhinal plus entorhinal cortex | Impaired (verbal) | Normal | Bowles et al. (2007, 2011) |
| **MR** (female) | Entorhinal cortex only | Impaired (words) | Intact | Brandt et al. (submitted) |
| **KN** (male; see 7.6) | Hippocampus, perirhinal spared | Normal | Greatly impaired | Aggleton et al. (2005) |

### Recall memory

Some recall research appears in Chapter 6. Here the question is whether **free recall** uses processes like those of recognition.

> **Key study, Staresina and Davachi (2006).** Three tests: **free recall**, **item recognition** (familiarity) and **associative recognition** (recollection). Success on **all three** was linked to increased activation **at encoding** in the **left hippocampus** and **left ventrolateral prefrontal cortex**, with the link **strongest for free recall** and **weakest for item recognition**. Only successful later **free recall** was linked to extra activation in the **dorsolateral prefrontal cortex** and **posterior parietal cortex**.

Why should free recall need those extra regions? The most likely answer is that successful free recall required **forming associations** at study (in this experiment, between items and the colours they were studied in), and recognition did not require such associations.

> **Key study, Mickes et al. (2013): remember/know in free recall.** For each studied word, participants answered either an **animacy** question ("animate or inanimate?") or a **size** question ("bigger than a shoebox?"). They then freely recalled the words, gave a remember or know judgement for each recalled word, and said which question had gone with it. The results paralleled recognition. First, many recalled words received each kind of judgement, with about **twice as many "remember" as "know"** responses. Second, people were **more accurate about the encoding question** for words they "remembered" than for words they "knew", just as remember responses in recognition come with more contextual information.

So the familiarity/recollection distinction applies to free recall too, not just to recognition.

### Is episodic memory constructive?

It is tempting to think episodic memory ought to work like a video recorder, giving an accurate, detailed replay of the past. It does not. Schacter and Addis (2007) describe episodic memory as **constructive rather than reproductive** and therefore prone to many kinds of error and illusion. Other chapters supply the evidence: people recall stories in distorted form (Chapter 10) and eyewitnesses produce distorted memories of crimes (Chapter 8).

Why would we have a memory system so prone to error? Schacter and Addis (2007; see also Schacter, 2012) give **three reasons**:

1. **Cost.** Keeping a semi-permanent record of every experience would require an enormous amount of processing.
2. **Gist is what we want.** We usually want the essence of past experiences, without the trivial details.
3. **Imagining the future (probably the most important).** We use the episodic system to **imagine possible future events and scenarios**, which is valuable for planning. Only a flexible, constructive system can recombine fragments of the past into new possible futures; a rigid recorder could not.

Classic background: the constructive view goes back to **Bartlett (1932)**, whose participants reshaped an unfamiliar folk tale to fit their own cultural expectations when they recalled it. The 7th edition names Bartlett as the origin of the assumption.

### Findings: gist and false memory in development

The tendency to remember **gist** increases through childhood (Brainerd et al., 2008), which is unsurprising. What is surprising is that this growing reliance on gist can **increase** certain memory errors as children get older.

> **Key study, Brainerd and Mojardin (1998).** Children heard sets of three related sentences, such as "the coffee is hotter than the tea", "the tea is hotter than the cocoa", "the cocoa is hotter than the soup". At test they judged whether each sentence had been presented **in exactly that form**. The critical items kept the **meaning** of an original sentence but changed the **wording** (for example, "the cocoa is cooler than the tea"). **False recognition of these meaning-preserving sentences was higher in older children than in younger ones.**

> **Trap.** Counter-intuitive direction: **older** children made **more** of these false recognitions, because they rely more on gist.

### Findings: imagining the future

If imagining the future uses the same or similar processes as remembering the past, episodic regions such as the hippocampus should be active during future imagining.

> **Key study, Viard et al. (2012), meta-analysis.** Most imaging studies found **hippocampal activation** when people imagined future events. Activation was greater when the cues were **personally relevant** rather than impersonal, and when the imagined events were rated **vivid, emotional or personally significant**. There is often **more** hippocampal activation for imagining the future than for recalling the past.

Why more? **Gaesser et al. (2013)** argued that the extra activation reflects the demands of **constructing** a coherent imaginary event. As they predicted, hippocampal activation was greater when imagined events were **constructed** for the first time than when they were **re-imagined**.

Activation shows correlation, not necessity. Stronger evidence would come from showing that people with very poor episodic memory, such as amnesic patients with hippocampal damage, are also poor at imagining the future.

> **Key study, Hassabis et al. (2007).** Amnesic patients and controls imagined new scenes (for example, lying on a white sandy beach in a beautiful tropical bay). The patients' imagined experiences were **isolated fragments**, lacking the richness and **spatial coherence** of the controls' scenes.

**Addis and Schacter (2012)** reviewed work on amnesic patients with hippocampal damage: most studies found **some** adverse effect of amnesia on imagining the future.

**Why is imagination impaired?** **Race et al. (2011)** pointed out two possibilities: hippocampal damage might (1) reduce access to detailed episodic information from which to build a future event, or (2) reduce the general ability to **construct narratives**. To separate them, they had amnesic patients build narratives from **presented pictures**, which needs no episodic retrieval. Their performance was **normal** on that task, but **severely impaired** when constructing narratives about **future events**. So amnesic patients' **narrative ability is preserved**; what is missing is the episodic raw material.

### Evaluation

**Strengths.** The assumption, running from Bartlett (1932) onwards, that episodic memory relies heavily on constructive processes is well supported (see also Chapters 8 and 10). The newer idea that the same or similar constructive processes are used to **imagine future events** is an exciting development, with reasonable support from both neuroimaging and amnesic patients.

**Limitations.**

1. We do not know in detail **why** imagining the future generally produces **more** hippocampal activation than remembering the past (Gaesser et al.'s construction account is a start).
2. Imagining the future needs processes **over and above** those used for recalling the past, and these processes remain **ill-specified**.

## 7.4 Semantic Memory

Semantic memory is where our organised general knowledge lives, and it is wildly varied: the French language, the rules of hockey, capital cities, who wrote which famous book. Much of it is held as **concepts**, mental representations of **categories** of objects or items. This section asks four questions about concepts and larger knowledge structures: how they are organised into levels, what their representations are made of, where in the brain they are integrated, and how they relate to schemas.

### Hierarchies of concepts

Shown a photograph of a chair and asked what it is, you could truthfully say "a piece of furniture", "a chair" or "an easy chair". That suggests concepts are arranged in **hierarchies**. **Rosch et al. (1976)** proposed three levels:

| Level | Example | Position |
|---|---|---|
| **Superordinate** | Furniture | Top |
| **Basic level** | Chair | Middle |
| **Subordinate** | Easy chair | Bottom |

We do sometimes talk at the extremes ("that furniture is expensive"; "I love my new iPhone"), but we usually deal with objects at the **basic level**.

**Why the basic level is special.** Rosch et al. (1976) had people list the **attributes** of concepts at each level:

- **Superordinate** categories got **very few** attributes, because they are abstract (what do all pieces of furniture share?).
- **Basic and subordinate** categories both got **many** attributes.
- But at the **subordinate** level, **different** categories got **very similar** attribute lists (an easy chair and a kitchen chair share most of what you know about chairs).

So **informativeness is low at the top** and **distinctiveness is low at the bottom**. The **basic level** gives the **best balance between informativeness and distinctiveness**.

The basic level has further special properties:

1. It is the **most general level at which people use similar motor movements** with category members: nearly all chairs are sat on in the same way, which is quite different from how we use tables.
2. It is usually the level **children acquire first** (Bourdais & Pecheux, 2009).
3. It dominates naming. When Rosch et al. (1976) asked people to name pictures of objects, they used **basic-level names 1,595 times**, **subordinate names 14 times** and **superordinate names once**.

The preference is not absolute. A botanist would name the individual plants in a garden rather than call them all "plants", and the findings below describe the main exceptions.

Classic background: older syllabi pair Rosch with **Collins and Quillian's (1969) hierarchical network model** (concepts as linked nodes, properties stored at the highest applicable level, verification time rising with levels traversed). It is not part of this 7th-edition chapter but is still asked in Indian papers.

### Findings: experts, faces and familiar objects

> **Key study, Tanaka and Taylor (1991).** Birdwatchers and dog experts named pictures of birds and dogs. Each group used **subordinate names** far more often in its **own** domain. **Bird experts** used subordinate names **74%** of the time for birds; **dog experts** **40%** of the time for dogs. In their **novice** domain, both groups used subordinate names only **24%** of the time.

**Faces** are the one kind of object we mostly categorise at the subordinate (individual) level.

> **Key study, Anaki and Bentin (2009).** A category label at the superordinate, basic or subordinate level was followed by a picture of a **familiar (celebrity) face**, and participants decided whether label and face matched. Matching was **faster at the subordinate or exemplar level than at the basic level**, presumably because nearly everyone is a face expert. **Is expertise needed?** Anaki and Bentin argued **no**: with photographs of **familiar towers** (the Eiffel Tower, the Leaning Tower of Pisa), matching was again faster at the **subordinate** level than the basic level. Individual **familiarity** with particular objects is enough to make subordinate categorisation very fast.

**Preferred is not the same as fastest.**

> **Key study, Prass et al. (2013).** Participants categorised **very briefly presented** photographs at the superordinate level (animal or vehicle), basic level (cat or dog) or subordinate level (Siamese versus Persian cat). Categorisation was **most accurate and fastest at the superordinate level** and **least accurate and slowest at the subordinate level** (Figure 7.4 in the book plots accuracy and speed across the three levels).

Why should the superordinate level win on speed? Basic-level categorisation is **more informative** and so needs **more detailed processing** (Close & Pothos, 2012). Deciding "animal" requires less information than deciding "cat".

> **Key study, Rogers and Patterson (2007).** Patients with **severe semantic dementia** performed **better at the superordinate level than at the basic level**, consistent with the idea that the superordinate level needs less detailed knowledge, which these patients still have.

> **Trap.** "The basic level is the fastest level" is **not** safe in the 7th edition. Basic-level names are **preferred** (1,595 versus 14 versus 1) and **learned first**, but **superordinate** categorisation is fastest under brief presentation (Prass et al., 2013), and **subordinate** is fastest for faces and familiar objects (Anaki & Bentin, 2009). Older keys equate basic with fastest.

### Using concepts: the traditional view

What do concept representations actually look like? This is contested (Kiefer & Pulvermüller, 2012; Meteyard et al., 2012). Until fairly recently most theorists assumed three things:

1. Concepts are **abstract**, detached from sensory input and motor output.
2. They are **stable**: a given person uses the same representation of a concept on every occasion.
3. They are **shared**: different people have fairly similar representations of the same concept.

Barsalou (2012) summed up this tradition as treating concepts like **detached encyclopaedia entries** in a database of category knowledge. The problem is that such entries seem remote from everyday life: how would you use a dictionary-style definition to perceive a scene or decide what to do?

### Barsalou's situated simulation theory

**Barsalou (2009, 2012)** argued that **all three** traditional assumptions are wrong. In daily life concepts are rarely processed in isolation. They are processed in particular **settings**, and processing is shaped by the current **context**. The representation of a concept therefore **varies across situations**, depending on the person's **current goals** and the main features of the situation.

His example is the concept **bicycle**. The traditional view predicts that a fairly complete abstract representation, something like a dictionary entry about a two-wheeled, pedal-driven vehicle, is activated every time. Barsalou says which aspects are activated depends on your goal: if you need to **repair** the bike, information about the **tyres** becomes prominent; if you want to **ride** it, the **height of the saddle** matters.

His positive proposal is **situated simulation theory**: concept processing typically involves the **perceptual** and **motor (action)** systems. To think about a concept is partly to re-enact, or simulate, the perceptions and actions associated with it.

### Findings: perceptual involvement

> **Key study, Wu and Barsalou (2009).** Participants listed properties for nouns or noun phrases. Those given **lawn** focused on **external** properties (plant, blades); those given **rolled-up lawn** listed more **internal** properties (dirt, soil). Likewise **watermelon** produced external properties (rind, green) and **half watermelon** internal ones (pips, red).

The point is that concept processing has a **perceptual, imagery-like** quality. Properties you would **not see** if you were actually looking at the object are harder to think of than those you would see. A purely abstract encyclopaedia entry should not care whether the lawn is rolled up.

> **Key study, Wang et al. (2010), meta-analysis.** Imaging studies of **concrete** concepts (objects we can see or hear) showed activation in regions such as the **fusiform gyrus, posterior cingulate and parahippocampal gyrus**, parts of the perceptual system also used in imagery. **Abstract** concepts (truth, freedom, invention) showed **little** sign of perceptual processing.

> **Key study, Wilson-Mendenhall et al. (2013).** These authors suspected Wang et al.'s null result for abstract concepts reflected **shallow processing**. They had participants think deeply about two abstract concepts. **Convince** activated regions linked to **social cognition** (for example, **medial prefrontal cortex**); **arithmetic** activated regions linked to **numerical cognition** (for example, the **intraparietal sulcus**).

> **Key study, Barsalou and Wiemer-Hastings (2005).** When people listed the characteristic properties of **abstract** concepts, many properties described **settings or events** associated with the concept (scientists working in a laboratory, for **invention**) and others described relevant **mental states**. Much of our knowledge of abstract concepts is therefore fairly **concrete** and involves perceptual properties.

### Findings: motor involvement

> **Key study, Hauk et al. (2004).** Tongue, finger and foot movements activate different parts of the **motor strip**. When participants read action verbs such as **"lick", "pick" and "kick"**, each verb activated the part of the motor strip overlapping with, or very close to, the region controlling the corresponding body part; "lick" activated tongue areas, for example. Several other studies have found similar effects (Pulvermüller, 2013).

The motor system seems to be involved even in **abstract** concepts. Emotionally **positive** abstract concepts (peace) elicit **approach** tendencies and **negative** ones (hostility) **avoidance** tendencies: people respond faster to positive stimuli with an approach movement and to negative stimuli with an avoidance movement (Pecher et al., 2011).

**Correlation or necessity?** These findings show motor activity accompanies action words. They do not show whether motor processing is **necessary** for understanding, or merely follows **after** the meaning has been accessed. Three lines of evidence speak to necessity:

1. **Patients.** People with widespread motor-system damage, such as **motor neuron disease** or **Parkinson's disease**, show a deficit in processing **action verbs** (hit, run) but **not other words**.
2. **Motor interference.**

> **Key study, Shebani and Pulvermüller (2013).** Participants processed **leg-related** words (step, kick) or **arm-related** words (grasp, peel) while **tapping** with their legs or hands. **Short-term memory** for the words was **worse** when word and movement **matched** (leg words with leg tapping) than when they did not (leg words with arm tapping) (Figure 7.5 in the book). The authors took this to show a genuinely motor contribution to word meaning.

3. **Brain stimulation.**

> **Key study, Pulvermüller et al. (2005).** Participants made **lexical decisions** (is this letter string a word?) while **TMS** was applied to parts of the **left-hemisphere motor strip** controlling the **arm** or the **leg**. **Arm words** were processed **faster** with TMS at the **arm** site than at the leg site, and **leg words** showed the opposite. Control experiments with TMS to the right hemisphere and with sham stimulation are shown in Figure 7.6 in the book. This is among the strongest evidence that motor-system processing is **necessary** for understanding action words.

> **Trap.** Direction matters. Pulvermüller et al. (2005): matching-site TMS made lexical decisions **faster**. Shebani and Pulvermüller (2013): a matching **movement** made memory **worse** (interference). Pobric et al. (2010a, below): TMS **slowed** naming.

### Evaluation of Barsalou's approach

**Strengths.** There is a lot of support for the general approach. Everyday use of concepts typically draws on the perceptual and motor systems, even for abstract concepts. This explains why concept processing varies with the person's goals and with the perceptual and motor processes the task engages.

**Limitations.**

1. **Barsalou overstates the variability.** He has not disproved the traditional view that concepts have a **stable, abstract core** (Mazzone & Lalumera, 2010). The book's verdict is that **both** approaches are partly right: concepts have a stable core **and** a context-dependent structure.
2. **Interpretation of perceptual and motor activation.** It may be central to meaning, as Barsalou argues, or it may happen only after meaning has been accessed. The evidence is increasingly that these processes are **necessary** for understanding (Pulvermüller, 2013), but the question is not fully settled.

### The hub-and-spoke model

Concept processing clearly involves the perceptual and motor systems, but it is unlikely to involve **nothing else**, for two reasons:

1. If the processing of a concept varied greatly from occasion to occasion, we would not have **coherent** concepts at all.
2. We can see that concepts belong together even when they are **perceptually very different**: scallops and prawns are both shellfish despite differing in shape, colour and movement (Patterson et al., 2007). Something must integrate across the modalities.

These points led several researchers (Patterson et al., 2007; Pobric et al., 2010b) to propose the **hub-and-spoke model** (Figure 7.7 in the book):

- The **spokes** are **modality-specific** sensory and motor regions; the figure lists spokes for **sounds**, **olfaction**, **praxis** (object manipulation), **somatosensory** information, **visual features** and **verbal descriptors**.
- Each concept also has a **hub**, a **modality-independent** (amodal) representation integrating everything we know about it, located in the **anterior temporal lobes**.

Why the anterior temporal lobes? Because **semantic dementia** always involves damage there, and a main problem early in the disease is extensive loss of conceptual knowledge across **all** modalities (Patterson et al., 2007). Patients cannot name an object from its **picture**, or from a **verbal description** (asked what we call the African animal with black-and-white stripes), or identify it from its characteristic **sound** (a dog barking). A deficit that spans pictures, words and sounds is what damage to an amodal hub should produce.

The model offers the best of both worlds: the **spokes** support our perceptual and motor dealings with the world (Barsalou's insight), while the **hubs** provide coherence and integration (the traditional insight about a stable core).

### Findings: the hub

> **Key study, Binder et al. (2009), meta-analysis.** Across **120 neuroimaging studies** of semantic memory, several regions were consistently active, and of most theoretical importance these included the **anterior temporal lobes** and related regions.

> **Key study, Mayberry et al. (2011).** Semantic dementia patients decided whether objects belonged to a category. The authors argued that losing "hub" information should **blur the boundary** between members and non-members of a category. So patients should particularly struggle with (1) **atypical** category members (an **emu** is an atypical bird) and (2) **pseudotypical** items, non-members that resemble members (a **butterfly** is bird-like). Both predictions held, for **pictures and for words** alike (Figure 7.8 in the book compares targets and foils). The fact that the deficit appeared in both modalities suggests anterior temporal processing is **general and hub-like** rather than modality-specific.

### Findings: the spokes and category-specific deficits

Evidence for spokes comes from **category-specific deficits**: disorders following brain damage in which semantic memory is disrupted for **particular semantic categories**.

The commonest is much greater difficulty identifying pictures of **living things** than **non-living things**. This is hard to interpret, because living things differ from non-living things in other ways: they have **more contour overlap** and are **structurally more complex**, while non-living things more often activate **motor** information. Patients probably struggle with living things mainly because of factors like these, not because the things are alive as such (Marques et al., 2013). Classic background: the living-things deficit was famously described by Warrington and Shallice (1984) in patients recovering from herpes simplex encephalitis.

> **Key study, Cree and McRae (2003).** They identified **seven** different patterns of category-specific deficit after brain damage. Each pattern differed in which concept **features** were most impaired; across the seven, the most impaired properties included **colour, taste, smell, visual motion and function** (what an object is used for). Concepts differ in which properties, perhaps corresponding to spokes, matter most for them.

> **Key study, Pobric et al. (2010a).** TMS briefly disrupted the **inferior parietal lobule**, thought to process the actions we can perform on objects. Naming was **slowed for manipulable objects** but **not for non-manipulable ones**. So the inferior parietal lobule, unlike the anterior temporal lobes, handles **relatively specific** concept processing: it behaves like a spoke (praxis), not a hub.

### Evaluation of the hub-and-spoke model

**Strengths.** It is **more comprehensive** than earlier approaches. The idea that concepts combine **abstract core information** with **modality-specific information** is well supported, and the relevant brain areas have been identified, with the anterior temporal lobes central to hubs.

**Limitations.**

1. **The hub may not be amodal.** **Mesulam et al. (2013)** studied patients with damage mainly or only in the **left** anterior temporal lobe. They had much more trouble with **verbal** concepts than with visually triggered object concepts, suggesting the left anterior temporal lobe is part of a **language network** rather than a fully general, modality-independent hub.
2. It is unclear **what information hubs contain**; for example, do very familiar concepts have richer hubs than less familiar ones?
3. It is unclear **how spoke information is integrated** with hub information.
4. The **number and nature of the spokes** remain unclear.

> **Trap.** **Hub = anterior temporal lobes** (semantic dementia; Binder et al., 2009). **Spokes = modality-specific regions** (category-specific deficits; Pobric et al., 2010a, inferior parietal lobule). **Mesulam et al. (2013)** is the **challenge** to an amodal hub. Pobric et al. (**2010b**) is the model paper; Pobric et al. (**2010a**) the TMS spoke study.

### Schemas

Semantic memory is not only a collection of simple concepts. Much of it consists of larger structures called **schemas**: well-integrated, organised packets of knowledge about the world, events, people or actions. Many schemas are **scripts**, schemas that hold information about a **sequence of events**. Your restaurant script probably runs: get the menu, order food and drink, eat and drink, pay the bill, leave (Bower et al., 1979). Classic background: the script concept was introduced by Schank and Abelson (1977).

Scripts are treated at length in Chapter 10 (language comprehension) and Chapter 8 (eyewitness errors). Here the key theoretical claim is that semantic memory holds **two major types of information**:

1. **Abstract concepts**, generally corresponding to individual words.
2. **Broader, more flexible organisational structures** based on schemas, such as scripts.

If that is right, some patients should find **concept** information harder to access than **schema** information, and others the reverse. There is some support for both predictions, more for the second.

### Findings: semantic dementia and scripts

> **Key study, Bier et al. (2013).** **Three** semantic dementia patients were asked what they would do if they discovered they had invited **two guests to lunch**. The script required dressing to go out, going to the grocery store, shopping for food, preparing the meal and clearing up. One patient, **MG, a 68-year-old woman**, described **all** these actions accurately despite the severe concept-access problems of semantic dementia. The other two **needed help**, particularly with **planning and preparing the meal**, though they remembered the actions for **dressing and shopping**.

### Findings: prefrontal damage and scripts

Scripts are **goal-directed** (you use the restaurant script to get a good meal), and the **prefrontal cortex** is crucial for forming and carrying out goals. So prefrontal damage should hit script memory especially hard.

> **Key study, Sirigu et al. (1995).** Patients with **prefrontal damage** generated **as many event-related actions** as controls but made **many more mistakes in ordering** actions within a script. They lacked the ability to assemble a script's contents into the right **sequence**.

> **Key study, Cosentino et al. (2006).** Patients with **fronto-temporal dementia** (damage to prefrontal cortex and temporal lobes), patients with semantic dementia, and healthy controls read scripts containing either **sequencing errors** (dropping the fish in the bucket **before** casting the line) or **semantic errors** (putting a **flower** on the hook in a fishing story). Semantic dementia patients and controls detected sequencing and semantic errors **equally often**. The fronto-temporal patients, with poor executive functioning, **missed almost twice as many sequencing errors as semantic errors**: relatively intact concept knowledge combined with severely impaired script sequencing.

> **Key study, Farag et al. (2010).** Scripts break down into **clusters**: the fishing script has a worm cluster (open the can of worms, put a worm on the hook) and a fishing-line cluster (cast the line, reel it in). Participants judged the order of consecutive events. Semantic dementia patients and controls were **sensitive to script organisation**, judging order better **within** clusters than **between** them. **Fronto-temporal dementia** patients were **equally poor** within and between clusters. Lesion mapping (Figure 7.9 in the book) showed that patients **insensitive** to script organisation had damage in **inferior and dorsolateral prefrontal** areas, whereas those sensitive to it showed **no prefrontal damage**.

### Conclusions on schemas

Patient research supports a distinction between **concept** and **script** knowledge: prefrontal damage often impairs script knowledge more than concept knowledge. But the two are closely linked. Using a script (preparing a meal) depends on concept knowledge (what the ingredients are). So semantic dementia patients, whose main loss is concept knowledge, **also** have great difficulty accessing and using scripts, as two of Bier et al.'s three patients showed.

> **Trap.** **Prefrontal / fronto-temporal damage** impairs script **sequencing**; **semantic dementia** impairs **concepts**, with scripts affected secondarily. Sirigu et al.'s prefrontal patients generated a **normal number** of actions; their problem was **order**.

## 7.5 Non-declarative Memory

Non-declarative memory shows itself in **behaviour**, not in conscious recollection. Its two major forms here are **priming** (also called **repetition priming**: faster or easier processing of a stimulus that has been met before) and **procedural memory** (mainly **skill learning**). Procedural memory is also what most research on **implicit learning** (Chapter 6) is measuring.

### Priming versus procedural memory

The two differ in two ways (Knowlton & Foerde, 2008):

| | **Priming** | **Procedural memory (skill learning)** |
|---|---|---|
| **Speed of acquisition** | Often **rapid**, even after one exposure | Typically **slow and gradual** |
| **Scope** | **Tied to specific stimuli** | **Generalises** to many stimuli |

The book's tennis example makes the second point: a backhand that only worked when the ball came from one direction at one speed would be useless. Skills must transfer to new instances; priming is about the particular item you met.

### The amnesic evidence, and its wrinkles

The single most important reason for separating declarative from non-declarative memory is that amnesic patients seem to have **severely impaired declarative** memory but **almost intact non-declarative** memory. **Hayes et al. (2012)** reviewed priming and skill learning in amnesic patients with **Korsakoff's syndrome**. Most studies found intact or nearly intact non-declarative performance, but some found **moderate impairment**. They offered three reasons for the exceptions:

1. Some tasks probably required **declarative as well as non-declarative** memory.
2. Some Korsakoff patients have **widespread damage** that may include regions needed for non-declarative memory.
3. The declarative/non-declarative distinction may be **less important** than traditionally assumed (the theme of 7.6).

### Repetition priming: perceptual and conceptual

There are two kinds of repetition priming:

- **Perceptual priming**: repeating a stimulus makes its **perceptual features** easier to process. A degraded stimulus is easier to identify if you have recently encountered it.
- **Conceptual priming**: repeating a stimulus makes its **meaning** easier to process. You decide faster whether an object is living or non-living if you saw it recently.

> **Trap.** **Perceptual** priming = **form** (identifying a degraded picture or a filtered spoken word). **Conceptual** priming = **meaning** (living/non-living judgement, category decisions). The brain regions differ too: perceptual priming goes with **early visual (occipital)** areas; conceptual priming with **lateral temporal** and **left prefrontal / left inferior frontal** regions (see Priming processes below).

### Findings: priming is spared in amnesia

If priming is non-declarative, amnesic patients should show it normally. Broadly they do, though sometimes with a modest deficit. Classic background: the earliest demonstrations were by Warrington and Weiskrantz (1968, 1970), whose amnesic patients completed word fragments with studied words as well as controls did, even though they could not recognise the words.

> **Key study, Cermak et al. (1985).** Amnesic patients were compared with **non-amnesic alcoholics** as controls (a control group presumably chosen to match the patients for alcohol history). The amnesic patients showed **as much perceptual priming** as the controls.

> **Key study, Levy et al. (2004): EP and GP.** Two male amnesic patients with **large medial temporal lobe lesions** decided whether studied and unstudied words belonged to given categories, a **conceptual priming** task. Their conceptual priming was **similar to controls'**, yet their **recognition memory** (declarative) was **much worse**.

> **Key case: EP (reviewed by Insausti et al., 2013).** EP had very extensive damage to the **medial temporal lobes**, including the **perirhinal cortex**. His long-term declarative memory was generally **even worse than HM's**: he could barely identify names, words and faces that had become familiar only after his amnesia began. Yet he was **intact on non-declarative tasks** such as **perceptual priming** and **visuo-motor skill learning**. Figure 7.10 in the book makes the contrast stark: EP's **recognition** was at **chance**, while his **perceptual priming** was at least as good as controls'.

> **Key study, Schacter and Church (1995).** Participants heard words all spoken in **one voice**, then identified the same words passed through an **auditory filter**. Priming appeared as better identification when the test voice matched the study voice, and amnesic patients showed this perceptual priming intact.

### The other half of the double dissociation

The case for separate systems would be stronger if some patients had **intact declarative memory but impaired priming**.

> **Key study, Gabrieli et al. (1995): MS.** A patient with a **right occipital lobe lesion**. MS performed **normally** on the declarative tests of **recognition and cued recall**, but was **impaired** on **perceptual priming** with certain visual tasks. Taken together with amnesic patients (impaired declarative, intact priming), this is a **double dissociation**.

> **Trap.** **MS** (Gabrieli et al., 1995) is the patient with **impaired priming** and **normal declarative memory**, after a **right occipital** lesion. **EP** is the opposite (declarative at chance, priming normal). Do not confuse MS with **NB** (impaired familiarity, perirhinal) or **MR** (entorhinal).

### A complication: priming that needs binding

> **Key study, Schacter et al. (1995).** The design resembled Schacter and Church (1995), with auditory word identification, but words were studied in **six different voices**. At test, half the words came in the **same voice** as at study and half in **one of the other study voices** (the **re-paired** condition). Healthy controls showed **more priming for same-voice words**; **amnesic patients did not**.

Reason through why. In **both** conditions every word and every voice had been heard before. The only advantage of the same-voice condition was that the particular **word-voice pairing** was preserved. That advantage helps only someone who **bound** each word to its voice at study. The amnesic patients evidently had not, which implies amnesics are poor at **binding different kinds of information** even on a task that looks non-declarative (see also Hannula & Greene, 2012). This finding foreshadows 7.6.

> **Trap.** Schacter and **Church** (1995): **one** study voice, amnesics show **normal** voice-specific priming. Schacter **et al.** (1995): **six** study voices with a re-paired condition, amnesics show **no** voice-specific advantage, because the advantage depends on **word-voice binding**. Same lab, same year, opposite results; the difference is whether binding was required.

### Priming processes: repetition suppression

What happens in the brain when priming occurs? A popular account is **perceptual fluency**: a repeated stimulus can be processed **more efficiently, with fewer resources**. In support, brain activity often **decreases** when a stimulus is repeated, a finding called **repetition suppression** (typically accompanied by better performance through priming).

The regions showing repetition suppression depend on the type of priming:

- **Perceptual priming**: reduced activity in **early visual areas** of the **occipital** lobe (Schacter et al., 2007).
- **Conceptual priming**: different areas; **Voss et al. (2008)** found repetition suppression in the **left prefrontal cortex**.

**Why should reduced activity go with better performance?** The most promising answer is the **synchrony model** (Gotts et al., 2012). Repeated stimuli make neurons fire at **lower rates**, and as a result they fire **more synchronously** with one another. Greater synchrony means **more efficient** neural processing, so less activity can produce a better response.

**Is the link causal?** Repetition causing both priming and reduced activity does not show that the reduced activity produces the priming.

> **Key study, Wig et al. (2005).** A **conceptual priming** task (classify objects as **living or non-living**). **TMS** was applied over the **left inferior frontal gyrus** to disrupt processing. For objects that had been accompanied by TMS, later classification showed **neither conceptual priming nor repetition suppression**. This suggests the region plays a **causal** role in conceptual priming. (The book's concluding sentence names the "left inferior temporal cortex", which looks like a slip; the region stimulated was the left inferior **frontal** gyrus.)

**Complications.**

1. **Repetition enhancement.** Several studies have found **increased**, not decreased, activity with repetition (Segaert et al., 2013). These enhancement effects probably depend on cognitive processes such as **attention and expectation**.
2. **Some "priming" is explicit strategy.**

> **Key study, Kessler and Moscovitch (2013).** In a **lexical decision** task (decide quickly whether a letter string is a word), words studied a few minutes earlier are classified faster, an effect long assumed to be implicit priming. But in earlier studies **only words** had been studied, so participants could use a simple **explicit strategy**: "if I recognise it from the study list, it must be a word". When Kessler and Moscovitch blocked that strategy by studying **equal numbers of words and non-words**, the **priming effect disappeared** (Figure 7.11 in the book shows response times for old and new words in the experimental and control groups).

The conclusion is that most of the usual lexical-decision priming effect comes from a **strategic, explicit** process, not implicit memory, which complicates the interpretation of every priming study that used lexical decision.

> **Trap.** Repetition **suppression** = **less** activity with repetition (synchrony model, Gotts et al., 2012). Repetition **enhancement** = **more** activity, linked to attention and expectation (Segaert et al., 2013).

### Procedural memory or skill learning

**Foerde and Poldrack (2009)** listed many types of skill learning, including **sequence learning, mirror tracing, perceptual skill learning, mirror reading and artificial grammar learning**. The tasks share a label but surely differ in their underlying processes. If amnesic patients show essentially **intact skill learning** alongside **severely impaired declarative memory**, that supports separate systems.

**A warning first: one task, two systems.** A given task is not always done with the same kind of memory. Consider the **weather prediction task**, in which participants learn to use cues to predict sunshine or rain.

> **Key study, Reber et al. (1996).** Amnesic patients learned the weather prediction task **as fast as controls**, suggesting it uses procedural (non-declarative) memory.

> **Key study, Foerde et al. (2006).** Participants did the weather prediction task **alone** or with a **demanding secondary task**. Performance was **similar** in the two conditions, but the **processes differed**. Under **single-task** conditions, performance correlated with activity in the **medial temporal lobe** (declarative). Under **dual-task** conditions, it correlated with activity in the **striatum** (part of the basal ganglia; non-declarative).

> **Key study, Schwabe and Wolf (2012).** On the same task, **non-stressed** participants relied mostly on **declarative** memory (**hippocampus**), whereas **stressed** participants relied more on **non-declarative** memory (**striatum**).

So the **same task** can be done mainly declaratively or mainly non-declaratively depending on **task conditions** (single versus dual task) and **participant state** (stressed or not).

> **Trap.** The weather prediction task is not simply "procedural". Undistracted and unstressed, people learn it mainly via the **medial temporal lobe**; **distraction** (Foerde et al., 2006) and **stress** (Schwabe & Wolf, 2012) push it **towards the striatum**.

### Findings: skill learning in amnesia

Amnesic patients often learn skills at intact or nearly intact rates across many tasks. Spiers et al. (2001), in their **147** cases, reported that **none** was impaired on learning **skills or habits, priming, simple classical conditioning or simple category learning**. Hayes et al. (2012) found much the same, though some studies showed a modest procedural impairment.

> **Key study, Tranel et al. (1994).** **28 amnesic patients** all learned the **pursuit rotor** as well as controls. The most striking was **Boswell**, whose damage was unusually extensive in regions central to declarative memory (medial and lateral temporal lobes). His pursuit-rotor learning **and his retention over two years** were comparable to controls'.

The **serial reaction time task** (Chapter 6) is a favourite: a stimulus appears at one of several locations and the participant presses the matching key as fast as possible. A repeating sequence is hidden in the trials, and non-declarative learning shows up as faster responding to the **repeating** sequence than to non-repeating sequences. Two conclusions carry over from Chapter 6: amnesic performance is typically **intact or slightly impaired**, and the task is not purely non-declarative, since healthy people often acquire some **consciously accessible** knowledge of the sequence (Gaillard et al., 2009).

> **Key study, Cavaco et al. (2004).** Most skill tasks used with amnesic patients are far removed from real life, so they used **five** skills resembling real-world ones, including a **weaving** task and a **control-stick** task like operating machinery. Amnesic patients learned at rates **comparable** to healthy people, despite significantly impaired **declarative memory for the same tasks** on recall and recognition tests.

> **Key study, Anderson et al. (2007).** Two **severely amnesic** patients were tested on **car driving**. Their steering, speed control, safety errors and driving with distraction were all comparable to controls'.

### Interacting systems

A central theme of the chapter is that traditional views were very oversimplified. The traditional assumption was that skill learning depends heavily on the **striatum** and declarative memory on the **hippocampus**. Foerde et al. (2006) and Schwabe and Wolf (2012) have already shown the balance between the two shifting with conditions.

There is growing evidence that skill learning usually involves **complex circuitry that includes the hippocampus**, traditionally tied only to episodic memory. **Albouy et al. (2013)** reviewed **motor sequence learning**: the hippocampus played a **crucial role** in acquiring and storing these procedural memories, and **hippocampal-cortical** and **striato-cortical** systems interacted extensively. Albouy et al. caution that hippocampal involvement does **not necessarily** mean learning was explicit.

**Robertson (2012)** argued that implicit and explicit memory are **functionally connected**.

> **Key study, Brown and Robertson (2007).** Participants learned a **motor skill** (procedural) and a **word list** (declarative). Motor-skill performance fell by **25%** when the word-list task was done during the retention interval; word-list performance fell by **10%** when the motor task was done during the retention interval. Each system interfered with the other, so the two can interact.

### How different are priming and skill learning?

If priming and skill learning depend on different systems, there is no reason why people good at one should be good at the other.

> **Key study, Schwartz and Hashtroudi (1991).** Priming was measured with **word identification** and skill learning with **reading inverted text**. There was **no correlation** between them.

Imaging could in principle help, but the wide range of tasks means many regions are active. Still, some patterns emerge.

**Skill learning.** The **striatum** is often involved. Practice is often accompanied by **decreasing prefrontal** activation and **increasing basal ganglia** activation. **Debaere et al. (2004)**, studying acquisition of a **hand-coordination** skill, found activation **decreases** in the **right dorsolateral prefrontal cortex, right premotor cortex and bilateral superior parietal cortex**, alongside **increases** in the **cerebellum and basal ganglia**.

**Parkinson's disease**, a progressive neurological disorder with severe **basal ganglia** damage, provides a test. Patients typically show **impaired skill learning**, but often impaired **explicit** learning too (Foerde & Shohamy, 2011), and some deficits may reflect **reduced motivation**. **Osman et al. (2008)** reviewed several studies in which Parkinson's patients learned skills well; in their own study, participants learned to control a **complex system (a water-tank system)**, and Parkinson's patients showed the **same procedural learning as controls**. So the striatum is **not needed for every** form of skill learning.

**Priming.** Schacter et al. (2007) found that visual **perceptual** priming often involves **early visual areas** of the occipital lobe, **conceptual** priming often involves the **lateral temporal cortex**, and there is frequently **increased synchronisation** of prefrontal activity with other regions. Where Schacter et al. emphasised reduced activation, **Segaert et al. (2013)** reviewed **29 studies** of **increased** activation and concluded that repetition enhancement effects turn up all over the brain.

The overall picture: priming and skill learning **typically involve different brain areas**, and perceptual priming different areas from conceptual priming, but firm conclusions are hard because priming is associated with so many regions.

### Evaluation

**Strengths.** Most evidence suggests repetition priming and skill learning are forms of non-declarative memory that often, though by no means always, involve different processes and brain areas from declarative memory. The strongest evidence is from amnesic patients, who typically show **intact or nearly intact** priming and skill learning. Despite that shared sparing, priming and skill learning differ in the brain areas involved.

**Limitations.**

1. **Task diversity.** Many different tasks have been used for perceptual priming, conceptual priming and skill learning, and more attention is needed to how their underlying processes differ.
2. **Inconsistent imaging.** The neuroimaging findings are variable and inconsistent, partly because of that task diversity.
3. **Too much focus on the striatum.** Until recently research over-emphasised the striatum. Understanding improves when we think in terms of **networks** rather than single areas (as argued in Chapter 1): motor sequence learning involves a **striato-cortical system**, not the striatum alone, and that system interacts with a **hippocampal-cortical system** (Albouy et al., 2013).

## 7.6 Beyond Declarative and Non-declarative Memory

Until fairly recently most memory researchers treated the declarative/non-declarative (explicit/implicit) distinction as of major theoretical importance. Its advocates make two linked assumptions:

1. The crucial difference between memory systems is whether they support **conscious access** to stored information.
2. Systems with conscious access depend heavily on the **hippocampus**; systems without it do not.

These assumptions shaped decades of research and drew reasonable support, but inconsistent findings are piling up. Either the traditional approach must be extended or a new one is needed. The book lists the problems first, then the processing-based alternatives.

### Problem 1: no task is purely explicit or implicit

If the main divide is between explicit and implicit memory, we need tasks that tap only one. In principle this seems easy: a task is **explicit** if the instructions tell participants to remember earlier material, and **implicit** if they do not. Reality is messier (Dew & Cabeza, 2011).

- **Word completion.** Participants study a word list and later, in an apparently unrelated task, complete word fragments (STR___) with the first word that comes to mind. Implicit memory is the tendency to complete fragments with studied words. Because the instructions never mention the list, this looks like an implicit task. Yet participants who **notice the connection** between the list and the completion task do **better** than those who do not (Mace, 2003), so explicit memory leaks in.
- **Autobiographical cueing.** People are given cues and asked to recall personal memories linked to them. That looks explicit, since there is an intention to recall, yet many of the memories produced arrive **involuntarily and spontaneously** (Uzer et al., 2012; Chapter 8).

### Problem 2: the brain does not respect the boundary

The traditional mapping linked the **striatum** to implicit memory and the **hippocampus** to explicit memory. But many supposedly implicit tasks involve the **hippocampus** (Foerde et al., 2006; Schwabe & Wolf, 2012; Albouy et al., 2013). Conversely, several studies have found **greater striatal activity** during episodic encoding for items later remembered than for items later forgotten (reviewed by Sadeh et al., 2011), and in Sadeh et al.'s own study effective episodic learning involved **interactive** hippocampal-striatal activity (7.1).

### Problem 3: consciousness is a shaky foundation

The distinction rests on **consciousness and awareness**, neither of which is well understood (Chapter 16). Ortu and Vaidya (2013) argued that building an entire classification of learning and memory on consciousness-based criteria may complicate rather than simplify scientific interpretation and progress.

### Processing-based accounts: Henke (2010)

Several theorists (Henke, 2010; Dew & Cabeza, 2011; Cabeza & Moscovitch, 2013) argue that the declarative/non-declarative framework should be **replaced**. The book uses **Henke's (2010)** model as the main example. Henke **rejects consciousness** as the criterion for dividing memory systems and instead classifies them by the **type of processing** involved (Figure 7.12 in the book, to be compared with the standard model in Figure 7.2). There are **three processing modes**:

| Processing mode | Memory it supports | Brain basis |
|---|---|---|
| **1. Rapid encoding of flexible associations** | **Episodic memory** (the model also assumes **semantic** memory often involves the hippocampus) | **Hippocampus** |
| **2. Slow encoding of rigid associations** | **Procedural memory, semantic memory, classical conditioning** | **Basal ganglia** (e.g., striatum) and **cerebellum** |
| **3. Rapid encoding of single or unitised items** (items fused into a single unit) | **Familiarity** in recognition memory, and **priming** | **Parahippocampal gyrus** |

Notice what has moved. **Familiarity**, which the traditional model files under declarative (episodic) memory, now sits with **priming** because both involve rapid encoding of single items. **Consciousness** plays no role in the classification at all.

### Where Henke's model and the traditional model disagree

On many points the two approaches agree. Both expect a hippocampal amnesic to be poor at episodic memory while keeping procedural memory and priming. The informative cases are where they **differ**:

| | **Henke (2010)** | **Traditional view** |
|---|---|---|
| **Prediction 1: hippocampus and unconscious learning** | Hippocampus encodes flexible associations whether learning is **conscious or unconscious** | Hippocampus is involved only in **conscious** learning |
| **Prediction 2: amnesic patients** | Should struggle to form flexible associations **even when learning is unconscious** | Only **conscious** learning should suffer |
| **Prediction 3: familiarity** | Hippocampus is **not directly involved** in familiarity | **All** episodic memory, familiarity included, depends on the hippocampus |

> **Trap.** Henke defines the hippocampus by **processing** (rapid, flexible **association**), not by **consciousness**, so she predicts hippocampal involvement in **unconscious** relational learning and amnesic failure on **implicit** relational tasks. Older keys built on Squire's taxonomy assume amnesics are spared on all implicit tasks; the 7th edition rejects that.

### Findings: Prediction 1 (the hippocampus in unconscious learning)

Hannula and Greene (2012) note it is often hard to be sure learning really happened **without** awareness, but they discuss several studies showing that associative or relational learning **can** occur unconsciously.

> **Key study, Duss et al. (2011).** **Face-occupation pairs** were presented **below** the level of conscious awareness. When the same faces were later shown **consciously**, participants showed some ability to classify them by **regularity of income** and **length of education** in line with the unseen occupation.

> **Key study, Henke et al. (2003).** Face-occupation pairs were again presented so that they could not be consciously seen. There was **hippocampal activation during non-conscious encoding** of the pairs, and **also during non-conscious retrieval** of the occupations linked to the faces at test.

### Findings: Prediction 2 (amnesic patients on implicit relational tasks)

> **Key study, Ryan et al. (2000).** Amnesic patients and controls viewed colour photographs of real-world scenes in three conditions: **novel** scenes; **repeated old** scenes (identical to before); and **manipulated old** scenes (seen before, but with some objects moved). **Eye movements** were recorded, and the key measure was the proportion of fixations on the **critical region** (the part altered in the manipulated condition). Controls fixated the critical region **more** in the manipulated condition than in the other two, even without being asked to remember anything. **Amnesic patients did not**, because they had **failed to bind objects to their locations** (Figure 7.13 in the book).

This is the 7th edition's model case: on an **implicit** measure, where the traditional view predicts normal performance, hippocampal amnesics failed because the task needed flexible associations.

Most evidence supports Prediction 2 (Henke, 2010), but there are exceptions.

> **Key study, Verfaellie et al. (2013).** Amnesic patients studied **word pairs** (mall-rain). In one implicit test condition, the first word was shown again (mall) with a **category name** (weather phenomena), and the task was to generate **four** category members. Implicit relational memory appeared as a higher probability of producing the paired target (rain) when its study partner was present. The amnesic patients showed **as much implicit relational memory as controls**.

Why the discrepancy is unknown. A possibly relevant difference is that Verfaellie et al. tested **verbal** associations, whereas earlier studies such as Ryan et al. (2000) tested other kinds of relational memory, such as memory for **scenes**.

### Findings: Prediction 3 (familiarity without the hippocampus)

Evidence from 7.3 already bears on this. Bowles et al. (2010) found amnesic patients with hippocampal damage had reasonably intact familiarity with impaired recollection. But the **typical** finding is that familiarity-based recognition **is** significantly impaired in amnesia, though much less than recollection (Skinner & Fernandes, 2007). How does that square with Henke? The likeliest answer is that amnesic patients' damage often spreads beyond the hippocampus into **adjacent areas**, including the **perirhinal cortex**, which supports familiarity.

> **Key study, Aggleton et al. (2005): KN.** A male amnesic patient with **hippocampal damage but no perirhinal damage**. His **recollection** was greatly inferior to controls'. Of more theoretical importance, his **familiarity** was **comparable to controls'** (Figure 7.14 in the book). With the hippocampus damaged and the perirhinal cortex spared, familiarity survives, as Henke predicts.

### Processing components: Cabeza and Moscovitch (2013)

**Cabeza and Moscovitch (2013)** discuss a **processing-component** approach. Like Henke's, it emphasises **processes** rather than systems, but it is **more flexible**. It assumes there are **numerous processing components** that can be **combined and recombined** for particular learning purposes. Memory systems, on this view, are temporary task-specific alliances; Dudai and Morris (2013) call them "ad hoc coalitions of computational modules that are recruited per task".

A major motivation is the neuroimaging evidence, in particular the finding that **brain regions attributed to one memory system contribute to tasks associated with other systems** (Cabeza & Moscovitch, 2013).

**Dew and Cabeza (2011)** proposed a model that links processes to brain regions (Figure 7.15 in the book). **Five brain areas** are placed along **three dimensions**:

| Dimension | Poles |
|---|---|
| **1. Cognitive process** | Perceptually driven versus conceptually driven |
| **2. Stimulus representation** | Item versus relational |
| **3. Level of intention** | Controlled versus automatic (involuntary) |

The five areas are the **visual cortex**, **parahippocampal cortex**, **hippocampus**, **rhinal cortex** and **left ventrolateral prefrontal cortex**. The figure is lost, so their positions on the three axes cannot be given; the point is that each region is described by its **processing profile**, not by a memory-system label.

### Evaluation of the component process approach

**Strengths.**

1. It fits the **neuroimaging evidence** better than the traditional memory systems approach.
2. It avoids the **excessive focus** on the declarative/non-declarative distinction.
3. Its flexibility explains why the **same task** can be performed with **different processes** depending on the person and conditions (Foerde et al., 2006; Schwabe & Wolf, 2012).

**Limitation.** As Cabeza and Moscovitch (2013) themselves admit, the approach is "fuzzy" and often fails to make **specific predictions**, so it is hard to test strongly. Even so, the idea that people learn and remember with many different combinations of specific processes is powerful and may guide future theory.

> **Trap.** The component process approach's **limitation** is that it is **fuzzy and hard to test**; fitting imaging data, de-emphasising the declarative/non-declarative split and explaining task flexibility are its **strengths**. Henke = three processing **modes**; Cabeza and Moscovitch = many recombinable **components**.

### Overall evaluation

The assumption of a fundamental split between declarative memory (needing the hippocampus) and non-declarative memory (not needing it) is **clearly oversimplified**. It predicts that amnesic patients should have **intact implicit relational memory**, and they do not (Ryan et al., 2000). The hippocampus appears to be needed for **relational or associative processing**, not for **conscious** processing as such.

More broadly, the traditional view that the hippocampus mainly serves episodic memory is **too narrow**. The hippocampus is connected to many regions (dorsolateral prefrontal cortex, temporal cortex, visual cortex, striatum), which helps explain why it seems to contribute to **perception, inference, imagining the future and decision making** (Shohamy & Turk-Browne, 2013).

Processing-mode (Henke, 2010) and processing-component (Cabeza & Moscovitch, 2013) theories handle several findings that trouble the systems approach and fit imaging evidence that many brain areas are involved in learning. Their weakness is that their **flexible assumptions are hard to test** stringently, a limitation that may shrink as they are developed. And, as the book reminds us at the start and the end, the traditional systems approach **might still be developed** to account for most of these findings.

## How the chapter fits together

1. **Patients carry the argument.** Almost every claim about separate systems rests on a dissociation: HM and EP (declarative lost, skills and priming spared); Beth, Jon and VJ (episodic lost, semantic acquired); semantic dementia (semantic lost, episodic spared); NB and MR versus KN (familiarity versus recollection); MS (priming lost, declarative spared). Read as pairs, these patients are the double dissociations on which the systems view rests.
2. **Every clean split leaks.** Episodic and semantic memory dissociate, yet share a network (Burianova et al., 2010), support each other (Kan et al., 2009; Greenberg et al., 2009) and merge over time (semanticisation). Lexical-decision priming turns out to be largely explicit (Kessler & Moscovitch, 2013); the weather prediction task uses the hippocampus unless people are distracted or stressed.
3. **Imaging shows correlation; lesions and TMS show necessity.** The book repeatedly discounts fMRI findings (Sadeh et al., 2011; Diana et al., 2007; Viard et al., 2012) and gives more weight to patients and TMS (Bowles et al., 2007; Hassabis et al., 2007; Pulvermüller et al., 2005; Wig et al., 2005).
4. **Binding is the hippocampus's real job.** Recollection is item-context binding; amnesics lose voice-specific priming when it needs word-voice binding (Schacter et al., 1995) and fail implicit object-location memory (Ryan et al., 2000). By 7.6 this is the thesis: the hippocampus serves relational processing, conscious or not.
5. **Concepts are stable and situated at once.** Rosch's levels, Barsalou's simulations and the hub-and-spoke model answer one question, and the verdict is a compromise: an amodal core (hub, anterior temporal lobes) plus goal-sensitive perceptual and motor detail (spokes).
6. **From systems to processes.** The chapter opens with Figure 7.2 (systems defined by consciousness and brain region) and closes with Henke (2010) and Cabeza and Moscovitch (2013) (memory defined by processing). The newer views fit more data but predict less.

## Worked example

*A 41-year-old teacher is seen eight months after a severe encephalitic illness. MRI shows bilateral hippocampal damage with perirhinal and anterior temporal cortex relatively spared. He repeats questions and cannot recall yesterday's therapy session, but his digit span is normal and his vocabulary and general knowledge are those of a well-read teacher. His childhood memories are vivid; the two years before the illness are largely gone. On the same unit, a 64-year-old woman with two years of progressive word-finding difficulty and anterior temporal atrophy cannot name a zebra from a description but recalls yesterday's appointment.*

**The first patient** has an amnesic syndrome: **anterograde** amnesia, **retrograde** amnesia with a **temporal gradient** (recent pre-illness years lost, childhood spared; Bayley et al., 2006), **normal short-term memory** (as in HM and all 147 of Spiers et al.'s cases) and preserved old **semantic** knowledge (like KC). Predictions, test by test:

- **Remember/know recognition:** few "remember" responses, near-normal "know" responses. Hippocampal damage with spared perirhinal cortex is the KN pattern (Aggleton et al., 2005), as the binding-of-item-and-context model predicts; ERPs should show an FN400 but little late positive component (Addante et al., 2012).
- **Perceptual priming and pursuit rotor:** normal (Cermak et al., 1985; EP; HM; Tranel et al., 1994).
- **New facts:** learnable but slowly and with heavy repetition, like Jon (Gardiner et al., 2008), because the cortex beneath the hippocampus is spared (Vargha-Khadem et al., 1997; VJ).
- **Category fluency:** below normal, especially for episodic-friendly categories such as birthday presents (Greenberg et al., 2009).
- **Imagining his next holiday:** fragmented (Hassabis et al., 2007), although he can build a narrative from a picture (Race et al., 2011).
- **Implicit eye-movement test with rearranged scenes:** the traditional view predicts normal performance because the test is implicit; Henke's model predicts failure because it needs object-location binding. Ryan et al. (2000) found failure.

**The second patient** shows **semantic dementia**: concept loss across modalities (description, and by prediction pictures and sounds) with episodic memory reasonably intact early (Adlam et al., 2009), from damage to the **hub**. Predict better superordinate than basic-level categorisation (Rogers & Patterson, 2007), errors on atypical members and pseudotypical foils (emu, butterfly; Mayberry et al., 2011), possibly preserved scripts (MG; Bier et al., 2013), and normal detection of script sequencing errors, which fronto-temporal patients miss (Cosentino et al., 2006).

**Together** they form the episodic/semantic **double dissociation**. **For rehabilitation**, the first patient's spared skill learning offers a route to new routines through practice rather than recall (Anderson et al., 2007; Cavaco et al., 2004), though tasks needing new associations may fail even without awareness. The second patient needs support for word and object meaning; her episodic memory is a strength.

## MCQ traps

1. **Schacter and Tulving (1994)**: **four** long-term systems (episodic, semantic, perceptual representation system, procedural); "five" in older sources includes working memory.
2. **Most common cause of amnesia** = **closed head injury**; **Korsakoff's** (chronic alcoholism, **thiamine** deficiency, preceded by **Wernicke's encephalopathy**) is the most *studied*.
3. **HM**: epilepsy from **10**, surgery **23 August 1953**, died **2008**, **Scoville and Milner (1957)**; mirror tracing retained **one year** (Corkin, 1968); post-onset famous faces: only **Kennedy and Reagan**.
4. **Anterograde** = after onset; **retrograde** = before onset. **Smith et al. (2013)**: **11** patients, **r = +0.81**.
5. **Declarative = explicit = knowing that**; **procedural = knowing how**; declarative includes some non-verbalisable memories.
6. **Priming is not procedural memory**: priming is **fast** and **stimulus-specific**; skills are **slow** and **generalise** (Knowlton & Foerde, 2008).
7. **Tulving (2002)**: episodic memory is **recently evolved, late-developing, early-deteriorating**; **Tulving (1972)** coined episodic/semantic.
8. **Spiers et al. (2001)**: **147** cases; episodic impaired in **all**; **no** STM deficit; **no** deficit in skills, priming, simple conditioning or simple category learning.
9. **Beth** (birth) and **Jon** (age **4**): normal-range semantic memory; Jon learns facts **more slowly** (Gardiner et al., 2008). **VJ**: impaired on **82%** of episodic tasks.
10. **Vargha-Khadem et al. (1997)**: episodic = **hippocampus**; semantic = **entorhinal, perirhinal, parahippocampal** cortices.
11. **Temporal gradient**: **remote** spared more than **recent**; consolidation theory needs an implausible **years-long** consolidation; **Kopelman and Bright (2012)**: no main theory supported.
12. **Semantic dementia** = **anterior temporal lobe**; episodic and executive function intact **early**; Adlam et al. (2009) normal what/where/when after **24 hours**.
13. **Harand et al. (2012)**: about **200** pictures, **3 days** and **3 months**; semanticisation runs **episodic to semantic**.
14. **Bahrick et al. (1975)**: about **90%** up to **25 years**; at nearly **50 years** only **name recognition** declined. **Permastore** = **Bahrick (1984)**. Grades: **54 years**, mostly inflated (Bahrick et al., 2008).
15. **Remember = recollection, know = familiarity**; **Dunn (2008)**, **37** studies, argued for **one** strength process; the book favours **dual-process**.
16. **FN400** = familiarity, **400 to 600 ms**; **late positive component** = recollection, **600 to 900 ms**.
17. **Diana et al. (2007)**: **perirhinal** = item/familiarity; **parahippocampal** = context; **hippocampus** binds them for recollection.
18. **NB** (perirhinal plus entorhinal) and **MR** (entorhinal only): **familiarity impaired, recollection intact**; **KN** (hippocampal, perirhinal spared): the reverse.
19. **Brainerd and Mojardin (1998)**: **older** children made **more** gist-based false recognitions.
20. **Schacter and Addis (2007)**: **three** reasons for constructive memory, the key one being **imagining the future**; hippocampus is often **more** active for future than past (Viard et al., 2012).
21. **Rosch et al. (1976)**: basic-level names **1,595**, subordinate **14**, superordinate **1**.
22. **Basic is preferred, not fastest**: **superordinate** fastest and most accurate (Prass et al., 2013); **subordinate** fastest for faces and familiar towers (Anaki & Bentin, 2009).
23. **Tanaka and Taylor (1991)**: subordinate names **74%** bird experts, **40%** dog experts, **24%** novice domain.
24. **Hauk et al. (2004)**: lick, pick, kick map onto **tongue, finger, foot**. **Pulvermüller et al. (2005)**: matching TMS made decisions **faster**; **Shebani and Pulvermüller (2013)**: matching movement made memory **worse**.
25. **Hub = anterior temporal lobes** (Binder et al., 2009, **120** studies); **Mesulam et al. (2013)**: left ATL looks **verbal**, not amodal. **Pobric et al. (2010a)**: TMS to **inferior parietal lobule** slowed **manipulable** objects only.
26. **Cree and McRae (2003)**: **seven** patterns of category-specific deficit.
27. **Prefrontal damage** disrupts script **order**, not number of actions (Sirigu et al., 1995); fronto-temporal patients missed **almost twice** as many sequencing as semantic errors (Cosentino et al., 2006).
28. **MS** (Gabrieli et al., 1995): **right occipital** lesion, impaired **perceptual priming**, normal recognition and cued recall.
29. **Schacter and Church (1995)**: **one** voice, amnesic priming normal; **Schacter et al. (1995)**: **six** voices, amnesics lost the same-voice advantage (binding).
30. **Wig et al. (2005)**: TMS to **left inferior frontal gyrus** abolished conceptual priming and repetition suppression; **synchrony model** = **Gotts et al. (2012)**.
31. **Kessler and Moscovitch (2013)**: lexical-decision priming **vanished** once non-words were studied too.
32. **Weather prediction task**: **striatum** under **dual-task** (Foerde et al., 2006) or **stress** (Schwabe & Wolf, 2012), medial temporal lobe otherwise.
33. **Tranel et al. (1994)**: **28** amnesics, **Boswell** retained pursuit rotor **two years**; **Brown and Robertson (2007)**: motor **25%** down, word list **10%** down.
34. **Henke (2010)**: **three** modes; **familiarity and priming** share the **parahippocampal** mode; **Ryan et al. (2000)** amnesics failed an implicit relational task; **Verfaellie et al. (2013)** the verbal exception.
35. **Dew and Cabeza (2011)**: **five** areas, **three** dimensions; the component approach's limitation is that it is **"fuzzy"**.

## Key terms

| Term | Definition |
|---|---|
| **Amnesia** | Severe impairment of long-term memory resulting from brain damage |
| **Korsakoff's syndrome** | Amnesia produced by chronic alcoholism, through thiamine deficiency |
| **Wernicke's encephalopathy** | Acute confusion, lethargy and inattention that usually precedes Korsakoff's syndrome |
| **Anterograde amnesia** | Reduced ability to remember information acquired after amnesia began |
| **Retrograde amnesia** | Poor memory for events and information from before amnesia began |
| **Amnesic syndrome** | Anterograde and retrograde amnesia, near-normal short-term memory, some residual learning |
| **Temporal gradient** | Older memories better preserved than recent ones in retrograde amnesia |
| **Declarative memory** | Long-term memory with conscious recollection of facts and events, "knowing that"; explicit memory |
| **Non-declarative memory** | Long-term memory shown in behaviour without conscious recollection; implicit memory |
| **Procedural memory** | Memory for "knowing how", including the knowledge behind skilled actions |
| **Priming** | Easier processing of a target because a related stimulus came earlier |
| **Episodic memory** | Memory for personal experiences tied to a particular place and time |
| **Semantic memory** | General knowledge of the world, concepts and language, abstracted from specific experiences |
| **Autobiographical memory** | Long-lasting memory for personally significant events |
| **Semantic dementia** | Anterior temporal lobe degeneration with widespread loss of word and concept meaning; episodic memory and executive function fairly intact early |
| **Double dissociation** | Group 1 impaired on A not B, group 2 on B not A; evidence for separate systems |
| **Semanticisation** | Episodic memories turning into semantic memories as context is lost |
| **Permastore** | Bahrick's term for very long-lasting memories of well-learned material |
| **Recollection** | Recognition from retrieving contextual details of the study episode |
| **Familiarity** | Recognition from perceived memory strength without contextual detail |
| **Remember/know procedure** | "Old" judgements labelled remember (recollection) or know (familiarity) |
| **FN400 / late positive component** | ERP markers of familiarity (400 to 600 ms) and recollection (600 to 900 ms) |
| **Binding-of-item-and-context model** | Perirhinal cortex for items, parahippocampal cortex for context, hippocampus binds them (Diana et al., 2007) |
| **Constructive memory** | Episodic memory rebuilds the past from gist and fragments rather than replaying it |
| **Concepts** | Mental representations of categories of objects or items |
| **Superordinate / basic / subordinate level** | Furniture / chair / easy chair in a concept hierarchy |
| **Situated simulation theory** | Barsalou: concept processing re-uses perceptual and motor systems and varies with goals and context |
| **Hub-and-spoke model** | Concepts combine an amodal anterior temporal hub with modality-specific spokes |
| **Category-specific deficits** | Brain-damage disorders disrupting semantic memory for particular categories |
| **Schema** | Organised packet of knowledge about the world, events or people in long-term memory |
| **Script** | Schema for a typical sequence of events (a restaurant meal) |
| **Perceptual priming** | Repetition facilitates processing of a stimulus's perceptual features |
| **Conceptual priming** | Repetition facilitates processing of a stimulus's meaning |
| **Repetition suppression** | Reduced brain activity with repetition, usually with better performance through priming |
| **Repetition enhancement** | Increased brain activity with repetition, probably reflecting attention and expectation |
| **Synchrony model** | Repetition lowers firing rates and raises neural synchrony, making processing more efficient (Gotts et al., 2012) |
| **Processing modes (Henke)** | Rapid flexible associations (hippocampus); slow rigid associations (basal ganglia, cerebellum); rapid unitised items (parahippocampal gyrus) |
| **Component process framework** | Memory uses many flexibly recombined processing components rather than a few systems (Cabeza & Moscovitch, 2013) |
| **Relational memory** | Memory for associations between items, such as objects and their locations |
